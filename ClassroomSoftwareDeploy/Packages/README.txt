Сюда Prepare-OfflineMedia.ps1 скачивает установщики, а администратор помещает вручную скачанные файлы.
Структура: Packages\<Id программы>\<файл установщика>.
Компьютеры назначения устанавливают программы только из этих локальных папок.
Не помещайте сюда web-страницы, ярлыки, bootstrapper без полного offline layout или непроверенные патчи.
