ЧЕК-ЛИСТ АВТОНОМНОГО USB-РАЗВЁРТЫВАНИЯ

ПОДГОТОВИТЕЛЬНЫЙ КОМПЬЮТЕР (ЕСТЬ ИНТЕРНЕТ)
[ ] Скопировать ClassroomSoftwareDeploy на внешний SSD/USB.
[ ] Запустить PREPARE-USB.cmd.
[ ] Проверить Config\OFFLINE-DOWNLOAD-RESULTS.csv.
[ ] Скачать вручную пункты из Config\MANUAL-DOWNLOADS.csv.
[ ] Для каждого EXE указать проверенные тихие аргументы в Config\apps.json.
[ ] Скачать Python wheels, Visual Studio layout и прочие компоненты, если нужны.
[ ] Убедиться, что все необходимые файлы находятся в Packages.
[ ] Проверить свободное место и безопасно извлечь носитель.

ЦЕЛЕВЫЕ КОМПЬЮТЕРЫ (ИНТЕРНЕТА НЕТ)
[ ] Подключить USB.
[ ] Запустить INSTALL-FROM-USB.cmd от имени администратора.
[ ] Проверить Logs и приложения после установки.
[ ] Провести тест на одном ПК перед установкой на остальные.
