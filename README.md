# ProgramScraper

Сбор сведений об установленных программах Windows 10/11 в один `.xlsx` с отдельными листами.

## Запуск

1. Двойной клик по **`Run.bat`**.
2. Подтвердите запрос UAC — права администратора нужны, чтобы прочитать `NTUSER.DAT` пользователей, которые сейчас не вошли в систему.
3. После завершения последний отчёт откроется автоматически.

Все отчёты сохраняются в папке `Reports`, имя файла выглядит как
`Programs_<ИМЯ_ПК>_<дата>_<время>.xlsx`.

## Листы отчёта

| Лист | Что содержит |
| --- | --- |
| Сводка | Информация о ПК/ОС, права, источники данных, количество строк |
| Программы пользователя | Uninstall-ключи пользователей (current + остальные профили) |
| Программы системы x64 | HKLM 64-bit Uninstall |
| Программы системы x86 | HKLM 32-bit Uninstall (WOW6432Node) |
| Windows и компоненты | Компоненты Microsoft, .NET, Visual C++, Runtime и т.п. |
| Обновления KB | KB из реестра и `Win32_QuickFixEngineering` |
| Автозагрузка | Run-ключи и папки Startup |
| winget | Список winget, если он установлен |
| Драйверы | `Win32_PnPSignedDriver` |

## Ручной запуск

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Get-InstalledPrograms.ps1
```

Дополнительные ключи: `-SkipWinget`, `-SkipAutostart`, `-OutputDir <путь>`.

## Особенности

- Не требует Microsoft Excel и сторонних PowerShell-модулей: `.xlsx` собирается через Open XML + ZIP средствами .NET.
- `.ps1` сохранён в UTF-8 с BOM (иначе Windows PowerShell 5.1 неверно читает кириллицу).
- Временно смонтированные кусты `NTUSER.DAT` выгружаются после сбора; кусты, оставшиеся от предыдущего прерванного запуска (`HKU\PSRep_*`), выгружаются автоматически в начале работы.
- Если выгрузить куст не получается, в конце печатается предупреждение с причиной, а данные из такого куста всё равно попадают в отчёт.
- При запуске без прав администратора читаются только загруженные кусты пользователей — отчёт всё равно создаётся.
